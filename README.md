# Excel-Finance-Analytics-Projects
Financial data cleaning, data preparation, and interactive dashboard creation using Microsoft Excel and Power BI.

## Project Overview
This project demonstrates the analysis of a company's financial performance by evaluating Revenue, Expenses, Gross Profit, and Net Profit across different regions, months, and product categories.

The objective of this project is to provide meaningful business insights through financial reporting and interactive dashboards, enabling users to compare performance and identify areas for improvement.

This project simulates real-world financial analysis responsibilities performed by Accounts Executives and Finance Analysts.
---
## Tools Used

### Microsoft Excel
- Data cleaning and preparation
- Financial calculations using Excel formulas
- Data formatting and validation
  
### Pivot Tables
- Interactive financial reports
- Income Statement preparation
- Revenue and Expense summaries

### Power BI
- Interactive dashboard creation
- KPI Cards
- Charts and visualizations
- Business performance analysis

### Power Query
- Data transformation
- Data cleaning
- Importing data from multiple sources
---
## Financial Analysis  
The project includes:
1. Total Revenue
2. Cost of Goods Sold (COGS)
3. Gross Profit
4. Operating Expenses
5. Profit Before Tax
6. Tax Expense
7. Net Profit

## Dashboard Features
 1. Monthly Revenue vs Expenses
 2. Profit by Region
 3. Expense Distribution
 4. Revenue by Product Category
 5. KPI Cards
 6. Interactive Slicers (Month, Region, Product Category)
